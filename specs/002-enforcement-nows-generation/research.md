| R3 | **Recognising an Enforcement-case NOW in H** (revised 2026-10-08, analysis I1/I3): first from the payload: any `nowContent.cases[].prosecutorOUCode` equal to the configured code (`GAPGD00`, JNDI) → enforcement; no external call.
