Decisions this plan rests on

  • v0.3.0 schema is the contract of truth — the CIMD-4372 examples do not validate against it. See artifact 001 and ADR-002.
  • Separate subproject, not a profile-gated package — matches the precedent set by the existing SOAP stub, and adds the runtime guard that stub lacks.
  • Declarative catalogue over typed assemblers — the Jira table is unstable, so table changes should be data edits.
  • Hand-written records + schema-validating ITs — the conformance test is the real AC1 guarantee and is needed either way.
  • All three endpoints in scope, with no security implementation this story.

Explicitly deferred

  • Security — token validation, TLS/mTLS. Excluded by direction.
  • Helm chart and non-live AKS deployment — separate infrastructure work.
  • Seeding the remaining 20 worked examples — mechanical, belongs with QA.
  • Resolving the 9 open questions — each has an interim behaviour; OQ-1 and OQ-7 risk rework.
